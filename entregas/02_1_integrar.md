# Item 2.1 — Dadosfera: Integrar

## 2.1.1 Objetivo
Integrar o dataset escolhido na Dadosfera via módulo de importação, garantindo volume mínimo (>= 100k) e preparando os dados para catalogação e camadas do Data Lake.
