# Case Dadosfera — Plataforma de Dados (E-commerce)

Repositório do case técnico seguindo o ciclo de vida dos dados: Integrar → Processar → Explorar → Analisar → ML/AI → IAM → Data Apps → GenAI.

## Estrutura
- `entregas/`: respostas item a item (Markdown)
- `assets/prints/`: prints de evidências (Dadosfera, dashboards, app)
- `docs/`: documentação complementar (arquitetura, KPIs, CDM, modelagem)
- `notebooks_colab/`: notebooks (Python, Data Quality, LLM, Similaridade)
- `app_streamlit/`: Data App em Streamlit (deploy no Streamlit Cloud)
